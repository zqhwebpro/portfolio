01 // WHAT IT IS & ATMOSPHERIC CONCEPT

The Subterranean Bunker Mainframe

Survival Quiz is an immersive interactive tactical terminal that simulates a cold-war era subterranean mainframe. Instead of a generic multiple-choice quiz, players step into the role of a military shelter administrator confronting existential crisis scenarios: bio-quarantine breaches, depleted calorie rations, armed incursions, and atmospheric radiation spikes.

The interface rejects modern clean minimalist design in favor of authentic tactile retro-computing: glowing monochrome green phosphor displays, cathode-ray curvature, interlaced scanlines, audible electromagnetic hums, and rhythmic Geiger counter crackles.

03 // CODING TECHNIQUES & IMPLEMENTATION

Engineering Mechanics & Algorithms

1. Pure CSS CRT Phosphor & Scanline Optics

Replicating an authentic analog cathode-ray tube screen typically requires an expensive WebGL fragment shader. In Survival Quiz, I achieved identical optical characteristics entirely through pure CSS:

  • Interlaced Scanlines: Generated using a repeating-linear-gradient overlay that draws alternating transparent and semi-opaque 2px horizontal bands.
  • Tube Curvature Vignette: A heavy radial-gradient vignette darkens the outer corners, mimicking the physical curvature of a glass monitor.
  • Phosphor Text Bloom: Layered text-shadow passes with varying blur radii (0 0 3px, 0 0 8px) recreate the electron-beam glow characteristic of P1 green phosphor.

2. Procedural 432Hz Drone & Web Audio Synthesis

To avoid loading heavy ambient audio files over slow network connections, the application features an integrated audio synthesis engine (FocusToneGenerator). It programmatically constructs a soothing 432Hz harmonic triad using native Web Audio nodes: 

class FocusToneGenerator {
    start() {
        if (this.isPlaying) return;
        const AudioCtx = window.AudioContext || window.webkitAudioContext;
        this.ctx = new AudioCtx();

        this.masterGain = this.ctx.createGain();
        this.masterGain.gain.setValueAtTime(0.001, this.ctx.currentTime);
        this.masterGain.gain.linearRampToValueAtTime(0.22, this.ctx.currentTime + 0.5);
        this.masterGain.connect(this.ctx.destination);

        // 432Hz harmonic triad: 108Hz sub-bass, 216Hz mid, 432Hz fundamental
        const harmonics = [
            { freq: 108, gainVal: 0.35, type: 'triangle' },
            { freq: 216, gainVal: 0.25, type: 'sine' },
            { freq: 432, gainVal: 0.18, type: 'sine' }
        ];

        harmonics.forEach(({ freq, gainVal, type }) => {
            const osc = this.ctx.createOscillator();
            const oscGain = this.ctx.createGain();
            osc.type = type;
            osc.frequency.setValueAtTime(freq, this.ctx.currentTime);
            oscGain.gain.setValueAtTime(gainVal, this.ctx.currentTime);

            osc.connect(oscGain);
            oscGain.connect(this.masterGain);
            osc.start();
        });
        this.isPlaying = true;
    }
}

3. Multi-Dimensional Psychological Vector Scoring

Standard quizzes tally simple binary scores ("Right vs Wrong" or "You scored 4/10"). Survival Quiz evaluates human ethics and survival philosophy using a continuous 4-dimensional normalized vector:

  • Pragmatism: Willingness to make cold, calculated decisions for group survival.
  • Empathy: Prioritization of human compassion and individual dignity over raw efficiency.
  • Fortitude: Resilience and perseverance when faced with physical exhaustion and hazard.
  • Risk Tolerance: Inclination toward high-stakes gambles versus conservative bunker defense.
// Updates psychological vector state upon selecting a directive option
const recordDirectiveDecision = (selectedOption, currentVector) => {
    const updated = { ...currentVector };
    
    // Add weighted delta from chosen option
    for (const [dimension, delta] of Object.entries(selectedOption.weights)) {
        updated[dimension] = Math.max(0, Math.min(100, (updated[dimension] || 50) + delta));
    }

    return updated;
};

// Classifies dominant survivor archetype from vector coordinates
const classifyArchetype = (vector) => {
    if (vector.pragmatism > 75 && vector.riskTolerance < 35) return "THE ARCHITECT";
    if (vector.empathy > 70 && vector.fortitude > 60) return "THE SHEPHERD";
    if (vector.fortitude > 80 && vector.riskTolerance > 70) return "THE VANGUARD";
    if (vector.riskTolerance > 80) return "THE WILDCARD";
    return "THE REALIST";
};

4. Deterministic State Machine with Full Rollback

The directive engine is modeled as a deterministic Directed Acyclic Graph (DAG). Every state transition appends a snapshot of the current decision index and vector coordinates to an immutable history array. This enables players to scrub back through prior dilemmas, review consequences, or test divergent ethical branches without resetting the entire session.

04 // ARCHITECTURAL TAKEAWAYS

Production Takeaways & Engineering Decisions

  • Pure CSS Performance Over WebGL Shaders

    Leveraging native CSS pseudo-elements for scanlines and CRT curvature eliminated 100% of WebGL canvas memory overhead, maintaining a silky 60 FPS even on low-powered mobile devices.

  • Procedural Audio Immersion

    Generating atmospheric drones mathematically via Web Audio created an unforgettable auditory mood while maintaining a 0 KB audio asset footprint and zero network dependencies.

  • Multi-Dimensional Vector Classification

    Replacing simplistic score tallies with a 4D psychological vector provided nuanced, satisfying narrative conclusions that resonated strongly with players.
