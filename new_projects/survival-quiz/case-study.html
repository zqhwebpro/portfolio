01 // WHAT IT IS

What It Is & Narrative Concept

Survival Quiz is an immersive interactive directive terminal that assesses human decision-making under existential pressure. Emulating an analog military mainframe in an abandoned subterranean bunker, the app presents players with severe tactical dilemmas—resource allocation, triage ethics, defensive posture, and quarantine directives.

Every response recalculates subtle internal alignment indexes (Pragmatism, Empathy, Fortitude, and Risk Tolerance), delivering a definitive survivor classification dossier upon completion.

02 // ARCHITECTURE & IMMERSION

Engineering & Analog Aesthetics

Engineered with modular JavaScript, CSS pseudo-raster optics, and Web Audio API synthesis:

  • Pure CSS CRT Screen Simulation

    Constructs authentic analog screen curvature, horizontal interlaced scanlines, and green phosphor bloom using stacked CSS linear gradients, radial vignettes, and text-shadow bloom without WebGL overhead.

  • Procedural Audio & Geiger Clicks

    Generates an eerie 60Hz subterranean drone and stochastic Geiger clicks using white-noise buffer bursts filtered through native Web Audio nodes, dynamically intensifying as hazard levels spike.

  • Multi-Dimensional Scoring Matrix

    Decisions feed a normalized weighted matrix that avoids naive binary outcomes, scoring responses across four psychological dimensions to yield nuanced character evaluations.
