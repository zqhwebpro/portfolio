Survival Quiz: Branching State Machine Terminal

Retro CRT terminal survival narrative with deterministic Directed Acyclic Graph state trees, CSS scanline shaders, and reactive Web Audio drones.

JavaScript (ES6+) State Machine Engine Web Audio Drones CRT Scanline Shaders Dynamic Consequence Tree
KEY TAKEAWAYS // ENGINEERING SUMMARY

Architecting this interactive survival quiz highlighted the efficiency of modeling non-linear narrative decisions using deterministic directed graph state machines. Structuring question paths with weighted consequence metrics allowed user choices to dynamically influence survival probabilities, unlock adaptive storylines, and branch into distinct endings. Prioritizing instant visual feedback through micro-animations and status meters significantly deepened reader engagement and tension during high-stakes dilemma questions. Ultimately, the build proved that clean modular state management enables rich interactive storytelling experiences without requiring complex backend database infrastructure.
