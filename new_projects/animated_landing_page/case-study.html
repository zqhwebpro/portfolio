Motion Landing Page: 3D Space & Physics

A high-performance celestial landing page featuring procedurally generated starfields, real-time mouse gravitational fields, and multi-layered CSS 3D solar body transforms.

Project Overview

The goal was to create a breathtaking, futuristic hero experience that demonstrates advanced web graphics capabilities. The application simulates deep space depth through multi-layer particle fields, orbital celestial mechanics, interactive meteor showers, and dynamic cursor gravitational interaction.

Technical Highlights

Layered Canvas System: Utilizes an optimized Canvas 2D particle simulation for hundreds of floating stellar bodies alongside CSS 3D spherical transforms for the central planet core and lunar maria textures.

Gravitational Pointer Physics: Mouse movements calculate proximity vectors against surrounding particles, displacing them with inverse-square dampening and restoring them smoothly to their resting orbits.

Responsive Parallax Engine: Device tilt (gyroscope) on mobile devices and cursor offsets on desktop drive subtle 3D parallax depth shifts across background nebulae.

What I Learned (Core Takeaways)

  • 🚀

    Hardware Acceleration Over Heavy DOM Elements

    Rendering hundreds of moving stars with DOM nodes causes severe layout thrashing. Moving particle updates to an offscreen Canvas while keeping typography in CSS delivers a smooth 60 FPS experience.

  • 🌌

    Micro-Interactions & Ambient Lighting

    Layering soft radial gradients with CSS blend modes (screen and color-dodge) creates convincing volumetric planetary atmospheres without the overhead of heavy 3D shaders.

  • ⚡

    RAF Throttling and Event Normalization

    Directly binding mousemove listeners to heavy calculations freezes the UI. Normalizing pointer coordinates into a shared state buffer and updating particle fields inside requestAnimationFrame keeps interactions buttery smooth.
