Chess PyCalc: Heuristic Position Evaluator

Retro terminal chess evaluation engine with dynamic Piece-Square Table matrices, FEN parsing, and sigmoid win-probability delta curves.

Vanilla JS (ES6+) Heuristic AI Piece-Square Tables FEN Parser CRT Scanline UI
KEY TAKEAWAYS // ENGINEERING SUMMARY

Building this project demonstrated how a robust Lexer-Parser tokenizer architecture transforms raw mathematical input into structured syntax trees, cleanly handling complex operator precedence and nested parentheses. Simulating a vintage CRT terminal interface highlighted the value of monospace typography, phosphor glow filters, and scanline shaders in establishing a focused user experience. Decoupling the arithmetic evaluation engine from UI state management ensured testable calculation logic and prevented edge cases with floating-point arithmetic. The implementation proved that pairing retro computer aesthetics with strict mathematical parsing creates an engaging, reliable developer utility.
