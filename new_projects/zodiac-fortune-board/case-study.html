KEY TAKEAWAYS // ENGINEERING SUMMARY

Summary of What Was Learned

Developing the Zodiac Fortune Board demonstrated how edge machine learning with MediaPipe hand tracking can replace conventional buttons with intuitive, touchless spatial interactions. Implementing temporal hysteresis on the gesture recognition loop proved crucial, ensuring deliberate fist holds register reliably while preventing accidental triggers during natural hand movements. Generating polyphonic bells, filter sweeps, and runic clatter purely through mathematical Web Audio oscillators eliminated external audio assets and zeroed out network latency. The project ultimately proved that complex geometric trigonometry, real-time computer vision, and procedural sound design can merge seamlessly in a standard browser tab without server dependencies.
