Most web applications treat user interaction as an exercise in clicking rectangular buttons or typing into search inputs. But ancient divination tools were tactile, solemn, and deliberate. An astronomer operating a 16th-century brass astrolabe rotated concentric dials by hand, aligning star needles with the zenith through physical touch. A cartomancer drawing tarot cards felt the card stock beneath their fingers.

With Zodiac Fortune Board, our goal was to recreate that physical, ritualistic intimacy in the browser. We wanted the webcam to act as a mystical Scrying Mirror—translating the user's natural body language into arcane divination spells. Achieving that without high cloud latency, clunky external libraries, or jittery false triggers required careful engineering across four core pillars: our architectural build choices, the mathematical building blocks, the hand tracking classifier engine, and the procedural audio system.

1. Build Choices: Zero-Cloud, Zero-Bloat

Before writing a single line of code, we established three strict non-negotiable engineering constraints:

The Architectural Pillars

  • Zero-Cloud Privacy & Sub-Millisecond Feedback

    Webcam frames must never leave the client. No cloud AI endpoints, no server-side vision APIs, and no telemetry. Processing runs 100% locally on the device's CPU/GPU via WebAssembly.

  • The Decision Against Heavy 3D Engines

    We deliberately avoided bundling Three.js or Babylon.js (which add 600KB–1.5MB of gzipped dependencies and mobile battery drain). Instead, the astrolabe is rendered using mathematical SVG polar geometry and GPU-accelerated CSS 3D transforms.

  • React 19 & Vite 8 Foundation

    Declarative component structure with instant HMR and tiny production bundles. Vite builds the entire client in under 200ms, while React's state machine cleanly coordinates the multi-stage divination flow.

By keeping all computation on-device and stripping away unnecessary library weight, the application achieves instantaneous boot times and immune resilience against network hiccups or API rate limits.

  • Trine Chords (120° Separation)

    Signs sharing the same elemental triad (Fire, Earth, Air, Water) sit 4 signs apart. The background calculates SVG vector lines connecting these trines, which ignite and pulse during celestial spells.

  • Opposition Vectors (180° Polarity)

    Opposing signs across the diameter of the wheel generate dynamic tension chords, forming the foundational sacred geometry mandala reminiscent of Doctor Strange Tao mandalas.

  • Zenith Needle & 30° Rotational Snapping

    A fixed top alignment pointer decodes the sign currently passing under the high noon needle using normalizedAngle = (-rotation % 360 + 360) % 360, triggering a mechanical tactile tick each time a 30° house boundary is crossed.

3. Hand Gesture Tech: From Pixels to Arcane Spells

Translating raw webcam video into rock-solid gesture controls is notoriously prone to false positives, camera noise, and wrist fatigue. To solve this, we implemented Google's @mediapipe/tasks-vision HandLandmarker with three critical architectural optimizations:

Decoupled Frame Loops & Ref Throttling

Running computer vision directly inside a standard React useEffect that calls setState on every frame will immediately drop frame rates to single digits. To ensure a locked 60 FPS UI:

  • Throttled ML Inference (~32ms / 30 FPS)

    While the browser animation loop runs at 60 FPS, the heavier MediaPipe neural inference is capped at ~30 FPS using performance.now(). This halves CPU/GPU thermal load while remaining imperceptible to the human eye.

  • Ref-Based Landmark Storage

    All 21 3D hand landmarks are stored in mutable React refs (rawLandmarksRef). The UI only triggers a state re-render when a discrete gesture classification actually changes.

The 5 Discrete Gesture Classifiers

Rather than ambiguous finger counting, we engineered 5 radically distinct geometric poses based on normalized Euclidean distance ratios between fingertips, MCP base knuckles, PIP middle knuckles, and the wrist root:

☝️ Pointing Navigation

Index finger extended; middle, ring, pinky curled down. Calculates angular velocity around the board center via Math.atan2(dy, dx) to spin the compass wheel smoothly.

✊ Clenched Fist Lock / Unlock

All 4 fingers curled down tightly toward the palm. Engaging this pose initiates the 3-second continuous hold lock engine.

✌️ Peace / V-Sign Horoscope

Index and middle fingers extended wide; ring and pinky curled down. Channels the Destiny Covenant horoscope reading.

✋ Open Palm Tarot Arcana

All 4 fingers extended wide apart. Manifests and draws the Major Arcana tarot card corresponding to the active sign.

🤘 Mystic Horns Elder Runes

Index and pinky extended; middle and ring curled down. Casts the Witches' Three Sacred Elder Runes (Past, Present, and Outcome triad).

useHandTracking.js Geometric Joint Distance Classifier 
// Extension detection using dual-ratio knuckle geometry
const isFingerExtended = (tip, pip, mcp) => {
  const tipToWrist = dist(tip, wrist);
  const pipToWrist = dist(pip, wrist);
  const tipToMcp = dist(tip, mcp);
  const pipToMcp = dist(pip, mcp);
  return (tipToWrist > pipToWrist * 1.05) && (tipToMcp > pipToMcp * 1.08);
};

const isIndexExtended = isFingerExtended(indexTip, indexPIP, indexMCP);
const isMiddleExtended = isFingerExtended(middleTip, middlePIP, middleMCP);

const isPinkyExtended = isFingerExtended(pinkyTip, pinkyPIP, pinkyMCP);

The 3-Second Hold Lock Architecture

A subtle but critical challenge in computer vision interfaces is accidental trigger drift. If a user points to align Scorpio at the Zenith, and then lowers their hand or relaxes their posture, inadvertent wrist rotation can spin the wheel away just as they try to read their horoscope.

The Deliberate Hold Pattern: To guarantee intentionality, the application requires the user to hold a clenched fist (✊ Fist) for 3.0 continuous seconds to lock or unlock the board.

When a fist is detected, a continuous timestamp timer starts. A radial SVG countdown HUD overlay renders on screen, counting down from 3.0s to 0.0s with an animated golden circular progress ring. If the user releases their fist early (e.g. at 2.1s), the lock sequence cancels safely without changing state.

Once the 3.0s threshold is reached:

  • Rotational Drift Immunity

    Wheel rotation is locked, so accidental pointer movements cannot disturb the Zenith alignment while examining readings.

  • Unmistakable Selected Node Signature

    The chosen sign node expands to 1.34x scale with a 4px imperial gold border, dual-layer glowing aura, continuous beacon pulse animation (@keyframes selectedBeaconWave), and an illuminated 👑 SELECTED badge.

  • Central Crystal Ball HUD

    The center orb illuminates with an imperial status pill: 🔒 [SIGN] LOCKED · Hold ✊ 3s to Unlock.

4. The Audio Tech: 100% Procedural Synthesis

In an era where web apps routinely bundle 20MB of compressed MP3 and WAV sound effects, we chose a fundamentally different path: every frequency in Zodiac Fortune Board is synthesized procedurally in real time using the native Web Audio API.

Zero external sound files means zero network latency, zero broken asset URLs, and zero loading spinners. Even more powerfully, procedural audio can be continuously modulated by user physics:

The 432Hz Sub-Bass Cosmic Drone

To immerse the user the moment the altar opens, a continuous harmonic drone hums in the background. It utilizes dual oscillators tuned to ancient Phrygian harmonic intervals (A1 at 54Hz and E2 at 81Hz) routed through a soft 140Hz low-pass Biquad filter:

mysticAudio.js Continuous Cosmic Drone Engine 
// Deep root 432Hz harmonic base: Root A1 (54Hz) + Fifth E2 (81Hz)
this.droneOsc1 = this.ctx.createOscillator();
this.droneOsc1.type = 'sine';
this.droneOsc1.frequency.setValueAtTime(54, now);

this.droneOsc2 = this.ctx.createOscillator();
this.droneOsc2.type = 'triangle';
this.droneOsc2.frequency.setValueAtTime(81, now);

// Soft low-pass filter to create warm subterranean ambient presence
const filter = this.ctx.createBiquadFilter();
filter.type = 'lowpass';
filter.frequency.setValueAtTime(140, now);

this.droneOsc1.connect(filter);
this.droneOsc2.connect(filter);
filter.connect(this.droneGain);

Dynamic Wheel Sweeps & Stochastic Rune Clatter

Other procedural audio modules include:

  • Velocity-Modulated Rotation Sweeps

    As the user spins the astrolabe wheel faster, a bandpass filter (Q=3, center=350Hz) dynamically sweeps its cutoff frequency proportional to angular velocity, creating an organic mechanical whoosh.

  • Cascading Stochastic Dice Bursts

    For elder runes and the 100-sided fate die, a micro-loop fires 5 rapid randomized square-wave clicks (400 + Math.random() * 500 Hz) spaced 70ms apart, resolving into a bright sine chime (E5 at 659Hz ramping to E6 at 1318Hz).

5. Lessons Learned & Takeaways

Building Zodiac Fortune Board reaffirmed that web development doesn't have to be sterile or bounded by standard form inputs. Key takeaways from the project:

  • Deliberate Timing Beats Instant Triggers

    In spatial/gestural computing, instant triggers lead to constant mistakes. Requiring a deliberate 3-second hold turned the fist gesture from an accidental hazard into a powerful, satisfying ritual.

  • Procedural Audio is an Undervalued Superpower

    Generating sounds mathematically via the Web Audio API allowed us to build an entire rich soundscape with zero download footprint and instant responsive modulation.

  • Edge Machine Learning is Production Ready

    Modern WebAssembly and WebGPU run multi-landmark neural models smoothly in ordinary browser tabs without any cloud infrastructure or privacy compromises.
