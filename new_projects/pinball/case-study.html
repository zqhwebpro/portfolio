01 // WHAT IT IS

What It Is & Concept

React Pixel Pinball is a complete browser recreation of classic mechanical pinball tables. Built entirely from first principles without relying on third-party gaming suites (like Phaser or Matter.js), the game models gravity, restitution, bumper kickbacks, and player-actuated flipper impulses directly in React state and Canvas rendering.

Players pull and release the mechanical plunger to launch balls into a neon playfield filled with slingshots, rollovers, drop targets, and high-frequency scoring bumpers.

02 // ARCHITECTURE & COLLISION MATHEMATICS

Engineering & Physics Simulation

Built using React state pipelines and low-level HTML5 Canvas vector math:

  • Discrete & Continuous Collision Detection

    To prevent "tunneling" (where fast-moving balls clip through thin walls between frames), the physics tick interpolates high-speed trajectories using line-segment ray intersection math alongside circle-to-circle bumper restitution.

  • Rotational Flipper Angular Impulse

    Flippers don't act as static angled walls—they calculate instantaneous tip velocity based on rotation angular speed, conferring proportional kinetic launch energy to balls struck during the upward stroke.

  • Procedural Retro Sound Generator

    Square and triangle wave oscillators generated via Web Audio API create arcade chime alerts, metallic bumper clacks, and game-over fanfares on demand with zero audio file latency.
