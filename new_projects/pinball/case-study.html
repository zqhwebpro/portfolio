React Pixel Pinball: 2D Arcade Engine

A custom-engineered retro pinball simulation combining HTML5 Canvas rendering, discrete collision geometry, spring-loaded plunger mechanics, and synthesized audio.

Project Overview

The objective was to build a full-featured, responsive arcade pinball game natively in the browser without relying on heavy external physics libraries like Matter.js or Box2D. The entire physics loop, collision solver, flipper rotational dynamics, and score multiplier engine were implemented from scratch.

The simulation delivers a smooth 60 FPS arcade cabinet experience that dynamically scales to any screen size while supporting keyboard inputs, touch triggers, and procedural Web Audio sound synthesis.

Technical Highlights

Decoupled Game Loop: The physics engine operates within a dedicated requestAnimationFrame loop using delta-time clamping. High-frequency state calculations (ball velocity, flipper angular momentum, particle sparks) are kept in memory and drawn directly to Canvas 2D rather than triggering React state updates.

Collision Detection & Resolution: Rigid-body collisions against sloped walls, circular bumpers, rollover lanes, and rotating flippers use continuous swept circle-line and circle-point projections to prevent tunneling at high ball velocities.

Audio Synthesis: Integrated Web Audio API oscillators synthesize authentic 8-bit chiptune bleeps and bumper strikes dynamically without latency or asset downloads.

What I Learned (Core Takeaways)

  • ⚡

    Separating React State from 60 FPS Render Cycles

    Passing physics positions through React state causes severe bottlenecking and dropped frames. Decoupling the game tick to mutate mutable ref buffers while using React strictly for HUD and high-score UI ensures persistent 60 FPS rendering.

  • 📐

    Continuous Collision Detection (CCD) Math

    High ball speeds cause discrete frame checks to skip over thin flipper geometry. Implementing sub-step integration and projection vector clamping eliminated ball clipping and guaranteed realistic rebounds.

  • 📱

    Responsive Viewport Matrix Transformations

    Arcade cabinets have fixed aspect ratios. Applying dynamic canvas scale matrices and touch event normalization ensured identical physics calculations across mobile phones, tablets, and wide desktop monitors.
