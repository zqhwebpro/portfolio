01 // WHAT IT IS

What It Is & Curriculum Purpose

Practical PHP Fundamentals is a hands-on technical suite demonstrating rock-solid server-side development. Instead of relying on bloated modern frameworks, it demonstrates how raw, secure web architecture is constructed from the ground up: session serialization, input sanitization, and cryptographic database transactions.

The curriculum explores three distinct engineering milestones: a 2D matrix game state engine, an RFC-compliant email transport sanitizer, and a cryptographically sound user registration and session management system.

02 // ARCHITECTURE & SECURITY SPECIFICATIONS

Core Architectural Implementations

Engineered with strict separation of concerns, defense-in-depth sanitization, and production security standards:

  • Tic-Tac-Toe: Session Matrix State Engine

    Implements in-memory 2D array representation inside $_SESSION with deterministic diagonal, rank, and file win evaluators, maintaining turn continuity across statutory HTTP postbacks without database overhead.

  • Email Contact Form: Header Injection Defense

    Enforces strict carriage-return / newline stripping on email headers (\r, \n, %0A, %0D) to prevent spambot SMTP injection, paired with comprehensive UTF-8 HTML entity escaping.

  • User Auth: PDO Prepared Statements & Bcrypt

    Eliminates SQL injection vulnerabilities via parameterized queries, secures user credentials with password_hash() using adaptive Bcrypt work factors, and prevents session fixation with session_regenerate_id().
