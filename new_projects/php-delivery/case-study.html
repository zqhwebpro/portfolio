Case Study: 3 Core PHP Projects

A structured technical analysis of foundational PHP development covering session state management (Tic-Tac-Toe), data sanitization and email dispatch (Contact Form), and cryptographic authentication with PDO and MySQL (User Registration & Login).

The 3 Core Learning Projects

Project 1 PHP Tic-Tac-Toe

Tic Tac Toe is an excellent beginner PHP project as it doesn’t involve a database or the file system. It gives you great experience handling forms, user sessions, arrays, and other PHP basics, and is a lot of fun as well!

Game Board Representation 3x3 grid stored in a 2D array in $_SESSION['board'].
Rendering the Board Dynamic HTML/CSS rendering loop generating coordinate buttons.
User Input Handling POST form submission passing (row, col) coordinates to PHP.
Game Logic Validation, 8-line win detection (checkWin()), and tie scanning.
Game Loop Alternating turn controller between Player X and Player O.
Game End & Reset Victory/tie banners with dedicated session restart button.

Project 2 Email Contact Form

A simple email contact form project is another great PHP beginner project. It includes an HTML form for collecting user input (name, email, subject, and message), a PHP script to filter, validate, and sanitize the input data, and the PHP mail() function to send the email.

HTML Form Collection Input fields for name, email, subject, and message with error states.
Input Filtering & Sanitization filter_var(), htmlspecialchars(), and trimming whitespace.
Header Injection Defense Regex filtering stripping carriage returns and newlines from headers.
mail() Function Constructing valid MIME UTF-8 headers and executing email dispatch.

Project 3 User Registration / Login System

A PHP project that handles user login and registration is much more complex than a simple contact form. It represents vital functionality for any e-commerce or social platform, establishing the foundation for database-driven web applications.

Database Setup (MySQL & PDO) users table schema with unique indices and secure PDO connections.
Registration Processing Uniqueness check, password_hash() Bcrypt hashing, and prepared INSERT.
Login Verification Querying user records, timing-safe password_verify(), and session setup.
Session & Logout Session regeneration (session_regenerate_id), cookie expiration, and session_destroy().

Application Security (AppSec) Principles Mastered

Building these three projects instilled a defense-in-depth mindset across common web vulnerabilities:

  • Cross-Site Scripting (XSS) & Email Header Injection Defense

    User-submitted content must never be echoed unescaped or placed directly into mail headers. Using htmlspecialchars($str, ENT_QUOTES, 'UTF-8') and stripping \r\n carriage returns prevents malicious payload injection.

  • Cryptographic Password Hashing vs Obsolete Hashing

    Never store plaintext or simple MD5/SHA1 hashes. PHP's password_hash($pass, PASSWORD_DEFAULT) automatically manages dynamic salting, cost factors, and adaptive cryptographic key derivation.

  • SQL Injection Prevention via PDO Prepared Statements

    Parameterized queries separate SQL instructions from user data, rendering SQL injection impossible regardless of input content.

  • Session Fixation Mitigation

    Upon verifying user credentials during login, calling session_regenerate_id(true) assigns a new session ID, preventing attackers from hijacking pre-authenticated session tokens.
