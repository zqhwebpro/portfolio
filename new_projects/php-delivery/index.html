PHP Tic-Tac-Toe (Sessions & 2D Arrays)

$_SESSION State 2D Array Grid

Tic-Tac-Toe is an excellent beginner PHP project as it doesn’t involve a database or the file system. It gives you great experience handling HTML forms, user sessions ($_SESSION), two-dimensional arrays, and conditional victory algorithms, and is a lot of fun as well!

1. Game Board Representation

A 3x3 grid stored as a two-dimensional array in $_SESSION['board'], initializing empty cells to represent coordinate slots [row][col].

2. Rendering the Game Board

A PHP rendering function iterating through row and column indices to dynamically generate styled HTML buttons and markers (X and O).

3. User Input Handling

Accepting moves via HTML forms using the POST method, passing target coordinates (row, col) back to the server controller.

4. Game Logic & Win Checks

Pure validation functions verifying cell availability, scanning all 8 winning lines (3 horizontal, 3 vertical, 2 diagonal), and detecting ties.

5. Game Loop & Turn Alternation

State loop alternating between Player X and Player O, committing the move to session memory, and verifying end conditions on each turn.

6. Game End & Session Reset

Displaying celebratory victory or tie notices, with a dedicated restart action resetting the session board state to blank.

PHP Win Check Implementation (checkWin):
function checkWin(array $b, string $p): bool {
    // Check 3 Horizontal Rows & 3 Vertical Columns
    for ($i = 0; $i < 3; $i++) {
        if ($b[$i][0] === $p && $b[$i][1] === $p && $b[$i][2] === $p) return true;
        if ($b[0][$i] === $p && $b[1][$i] === $p && $b[2][$i] === $p) return true;
    }
    // Check 2 Diagonals
    if ($b[0][0] === $p && $b[1][1] === $p && $b[2][2] === $p) return true;
    if ($b[0][2] === $p && $b[1][1] === $p && $b[2][0] === $p) return true;
    return false;
}

Secure Email Contact Form (Validation & mail())

mail() Function filter_var() Header Injection Defense

A simple email contact form project is another great PHP beginner project. This project includes an HTML form for collecting user input (name, email, subject, and message), a PHP script to filter, validate, and sanitize the input data, and the native PHP mail() function to send the email.

HTML Form Collection

Semantic <form method="POST"> collecting sender name, email address, subject, and message body with sticky input retention.

Input Sanitization & Filtering

Defensive filtering via filter_var($email, FILTER_SANITIZE_EMAIL), htmlspecialchars(), and trimming whitespace to neutralize XSS payloads.

Header Injection Prevention

Strict regex validation stripping carriage returns (\r) and line feeds (\n) from subject and email fields to thwart spam relay attacks.

Error Handling Array

Comprehensive validation pipeline collecting specific validation error messages in an $errors array before any email dispatch occurs.

Native mail() Dispatch

Formatting MIME headers (From:, Reply-To:, Content-Type: text/plain; charset=UTF-8) and invoking mail().

User Feedback Alerts

Conditional UI alert banners communicating successful dispatch or highlighting exact invalid fields for seamless UX.

PHP mail() & Sanitization Architecture:
$name    = trim($_POST['name'] ?? '');
$email   = filter_var(trim($_POST['email'] ?? ''), FILTER_VALIDATE_EMAIL);
$subject = preg_replace('/[\r\n]+/', ' ', trim($_POST['subject'] ?? ''));
$message = htmlspecialchars(trim($_POST['message'] ?? ''), ENT_QUOTES, 'UTF-8');

if ($email && !empty($name) && !empty($message)) {
    $headers = "From: webmaster@example.com\r\nReply-To: {$email}\r\nContent-Type: text/plain; charset=UTF-8";
    mail("contact@example.com", $subject, $message, $headers);
}

3 Intermediate Project • Full Database & Auth Pipeline

User Registration & Login System (PDO, MySQL & Bcrypt)

PDO Prepared Statements password_hash() password_verify()

A PHP project that handles user login and registration is much more complex than a simple email contact form. However, this represents vital functionality that any e-commerce or social media-based website needs, and provides the essential foundation for web application development.

1. Database Setup (MySQL & PDO)

Creating the users table schema with indexed unique columns (username, email) and initializing secure PDO connections with ATTR_EMULATE_PREPARES => false.

2. Registration Form

Collecting username, email address, password, and password confirmation with client-side pattern hints and server-side defensive re-validation.

3. Registration Script & Bcrypt

Filtering input, checking for duplicate username/email, hashing passwords with password_hash() (Bcrypt/Argon2), and inserting via prepared statements.

4. Login Form

HTML form collecting credentials (username/email and password) with CSRF token protection and secure POST transmission.

5. Login Script & password_verify()

Querying user records, executing timing-safe password_verify() against stored hashes, and invoking session_regenerate_id().

6. Logout & Session Invalidation

Executing session_unset(), session_destroy(), expiring the session cookie in the past, and redirecting safely to login.
