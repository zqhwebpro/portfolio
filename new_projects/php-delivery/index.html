1 Beginner Project • Zero DB Dependency

1. PHP Tic-Tac-Toe

Tic Tac Toe is an excellent beginner PHP project as it doesn’t involve a database or the file system. It gives you great experience handling forms, user sessions, arrays, and other PHP basics, and is a lot of fun as well!

Core Architectural Components

Game Board Representation

You'll need to create a 3x3 grid to represent the Tic Tac Toe board. You can use a two-dimensional array stored in $_SESSION['board'] to store the board state.

Rendering the Game Board

Create a function to display the game board on the screen. You can use HTML and CSS to style the board and PHP to generate the board dynamically.

User Input

Implement a way for users to input their moves. You can use HTML forms with POST or GET methods to accept user input and pass it back to the PHP script.

Game Logic

Create functions to handle game logic, such as checking for a win (rows, columns, diagonals), checking for a tie, and validating user input.

Game Loop

Implement a game loop that alternates between players (X and O), accepts user input, updates the board, and checks for a win or tie.

Game End

When the game ends, display a message indicating the winner or a tie and provide an option to restart the game and reset session state.

// 1. Initialize Board in Session
session_start();
if (!isset($_SESSION['board'])) {
    $_SESSION['board'] = [['','',''], ['','',''], ['','','']];
    $_SESSION['player'] = 'X';
    $_SESSION['winner'] = null;

// 2. Check 8 Winning Lines
function checkWin(array $b, string $p): bool {
    for ($i = 0; $i < 3; $i++) {
        if ($b[$i][0] === $p && $b[$i][1] === $p && $b[$i][2] === $p) return true;
        if ($b[0][$i] === $p && $b[1][$i] === $p && $b[2][$i] === $p) return true;
    }
    if ($b[0][0] === $p && $b[1][1] === $p && $b[2][2] === $p) return true;
    if ($b[0][2] === $p && $b[1][1] === $p && $b[2][0] === $p) return true;
    return false;
}

2 Beginner Project • Sanitization & Server-Side Email

2. Email Contact Form

A simple email contact form project is another great PHP beginner project. This project might include an HTML form for collecting user input (name, email, subject, and message), a PHP script to filter, validate, and sanitize the input data, and the PHP mail() function to send the email.

Additionally, you would need to incorporate basic error handling, the use of conditional statements, and server-side validation to ensure a seamless and secure user experience. This project helps beginners learn how to process user input, interact with server-side code, and gain a basic understanding of PHP email functionality.

Core Architectural Components

HTML Form Collection

Semantic HTML form collecting sender name, email address, subject, and message with POST submission and sticky input retention.

Sanitization & Validation

Server-side filtering via filter_var($email, FILTER_SANITIZE_EMAIL), htmlspecialchars(), and whitespace trimming.

Native mail() Execution

Assembling structured MIME headers (From:, Reply-To:) with CRLF injection defense and invoking mail().

PHP Implementation: Input Sanitization & Header Injection Defense filter_var() 
// 1. Sanitize & Validate Inputs
$name    = trim($_POST['name'] ?? '');
$email   = filter_var(trim($_POST['email'] ?? ''), FILTER_VALIDATE_EMAIL);
$subject = preg_replace('/[\r\n]+/', ' ', trim($_POST['subject'] ?? ''));
$message = htmlspecialchars(trim($_POST['message'] ?? ''), ENT_QUOTES, 'UTF-8');

// 2. Header Injection Defense & Dispatch
if ($email && !empty($name) && !empty($message)) {
    $headers = "From: webmaster@example.com\r\nReply-To: {$email}\r\nContent-Type: text/plain; charset=UTF-8";
    mail("contact@example.com", $subject, $message, $headers);
}

3 Intermediate Project • Full Database & Auth Pipeline

3. User Registration / Login System

A PHP project that handles user login and registration is much more complex than a simple email contact form. However, this represents vital functionality that any e-commerce or social media-based website needs, and could also be combined with the Simple CMS project mentioned earlier. Pursuing this project is well worth your time if you are serious in building a career in web development.

Primary Aspects of This Project

Database Setup

You'll need to create a database to store user information such as usernames, email addresses, and hashed passwords. This will involve creating a table with appropriate columns and setting up a connection using one of PHP's database extensions (PDO / MySQL).

Registration Form & Script

Create an HTML form that collects user input for registration. Write a PHP script that filters and sanitizes inputs, checks for existing users, hashes the password securely using password_hash(), and inserts the record.

Login Form & Script

Create a login HTML form. Write a PHP script that queries the database, verifies the submitted password against the hashed password using password_verify(), and creates a session to maintain logged-in state.

Logout Functionality

Implement a PHP script that allows users to log out by destroying the session (session_unset(), session_destroy()), returning them safely to the login page.

PHP Implementation: PDO Prepared Statements & Bcrypt Auth password_hash() & password_verify() 
// 1. User Registration with Bcrypt Hash
$hash = password_hash($password, PASSWORD_BCRYPT, ['cost' => 12]);
$stmt = $pdo->prepare("INSERT INTO users (username, email, password_hash) VALUES (?, ?, ?)");
$stmt->execute([$username, $email, $hash]);

// 2. Login Verification & Session Fixation Defense
$stmt = $pdo->prepare("SELECT * FROM users WHERE username = ?");
$stmt->execute([$username]);
$user = $stmt->fetch();

if ($user && password_verify($password, $user['password_hash'])) {
    session_regenerate_id(true); // Prevent Session Fixation
    $_SESSION['user_id'] = $user['id'];
}
