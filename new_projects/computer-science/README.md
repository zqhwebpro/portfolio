# THE 5 CONCEPTS OF PROGRAMMING // Neo-Brutalist Infographic

Headline: "5 Concepts. Every Language. Every Programmer."
Subtext: "Master these once — and you can code in any language."

An interactive educational single-page infographic web application that translates the 5 foundational programming concepts across all languages into interactive visualizers, cross-language syntax references (Java, C#, JS, Python), and an interactive FizzBuzz Case Study pipeline.

---

## 🎨 Design Philosophy: "Neo-Brutalist Bauhaus CS"

- **Color System**:
  - High-contrast stark white (`#FFFFFF`), rich paper background (`#F8F7F2`), and deep monochrome (`#0A0A0A`).
  - Bauhaus Accents: Canary Yellow (`#FFE600`), Cobalt Blue (`#0038FF`), Vermilion Red (`#FF2A00`), Mint Green (`#00E599`), Cyan (`#00F0FF`), and Purple (`#7928CA`).
- **Tactile Micro-Interactions**:
  - Crisp 2.5px–3.5px solid black borders, hard-drop geometric shadows (`4px 4px 0px #000`, `6px 6px 0px #000`), and active button snap offsets (`transform: translate(2px, 2px)`).
  - Procedural Web Audio API sound engine synthesizing mechanical clicks and success tones with zero external audio assets.

---

## 🔢 The 5 Core Concepts

1. **Take Input** (`01`) — *The program listens before it acts.*
   - Syntax: `Java → Scanner / System.in.read()`, `C# → Console.ReadLine()`
   - Interactive stdin buffer listener with keyboard typing simulation & raw stream inspector.
2. **Allocate Memory** (`02`) — *Store what you learn — from simple values to complex structures.*
   - Progression: `Primitives (int, string) → Objects → Trees & Lists`
   - Stacking memory stack visualizer with animated box drop and heap allocation.
3. **Give Output** (`03`) — *Turn raw results into something humans can actually read.*
   - Progression: `Console text → Tables → Dashboards`
   - Render format selector switching dynamically between stdout console text, tabular grids, and live dashboard widgets.
4. **Make Decisions** (`04`) — *If this, then that. The logic that drives every program.*
   - Progression: `if / else → ternary operators → nested logic`
   - Branching predicate test engine lighting up True (Green) vs False (Red) execution pathways.
5. **Loop** (`05`) — *Repeat the work so you don't have to.*
   - Progression: `for → while → foreach`
   - Continuous spinning iteration engine ticking 1→100 with live execution state.

## 💡 Real-World Proof (Case Study Strip)

- **"FizzBuzz in Action"**:
  - Connects all 5 concepts in sequence: `Take 2 inputs → Store as integers → Loop 1–100 → Decide Fizz/Buzz/Number → Output results in a table`.
  - Includes a 5-node animated flowchart illuminating each concept step-by-step and rendering an interactive output snapshot table with category filters (`ALL`, `FIZZ`, `BUZZ`, `FIZZBUZZ`).
