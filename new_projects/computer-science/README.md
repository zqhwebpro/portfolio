# THE GEOMETRY OF COMPUTATION // Neo-Brutalist Bauhaus CS Infograph

An interactive educational single-page infographic web application that translates foundational Computer Science theory into physical space, geometric state transitions, and responsive diagrams.

---

## 🎨 Design Philosophy: "Neo-Brutalist Art Pop x Bauhaus CS"

- **Color System**:
  - **High-Contrast Monochrome**: Stark white (`#FFFFFF`) and deep black (`#0A0A0A`) with architectural paper grid textures.
  - **Bauhaus / Art Pop Accents**: Electric Cobalt Blue (`#0038FF`), Acid Canary Yellow (`#FFE600`), and Punch Vermilion Red (`#FF2A00`), paired with Emerald Mint (`#00E599`) and Ultra Purple (`#7928CA`).
- **Tactile Micro-Interactions**:
  - Crisp 2px–3.5px solid black borders, hard-drop geometric shadows (`4px 4px 0px #000`, `8px 8px 0px #000`), and mechanical button snap offsets (`transform: translate(2px, 2px)`).
  - Procedural Web Audio API sound engine synthesizing mechanical clicks, frequency shifts for tree traversals, and stack push/pop pitches with zero external asset dependencies.
- **Performance**:
  - Direct `requestAnimationFrame` and raw DOM transforms via `useRef` for high-frequency cursor field distortion (60–120 FPS without React re-renders).

---

## 📐 Core Curricula & Interactive Modules

1. **Hero Section: "The Geometry of Computation"**
   - 12 interactive Bauhaus geometric primitives reacting to continuous cursor force fields with real-time Bubble Sort (by Area) and QuickSort (by Hue) state transitions.
2. **Concept 01: Big-O Complexity Arena**
   - Interactive vector coordinate graph comparing $O(1)$, $O(\log n)$, $O(n)$, $O(n \log n)$, $O(n^2)$, and $O(2^n)$.
   - Dynamic input $N$ scrubber with real-time operations computation and estimated CPU hardware execution time (nanoseconds to millennia).
3. **Concept 02: The Physical Call Stack Tower**
   - Physical call-frame tower visualizer with colored blocks stacking and popping as return values bubble down.
   - Includes Factorial ($n!$), Fibonacci ($F(n)$), and Recursive Array Reversal with synchronized line-by-line execution code highlighting.
4. **Concept 03: Graph & Binary Tree Traversals**
   - SVG vector tree with Breadth-First Search (BFS - FIFO Queue) and Depth-First Search (DFS - LIFO Stack) traversals, animated `stroke-dashoffset` edges, and traveling pulse particles.
5. **Concept 04: The Algorithm Race Arena & 2D Quadtree**
   - 4-way concurrent sorting race (QuickSort vs MergeSort vs InsertionSort vs BubbleSort) and an interactive 2D Quadtree spatial partitioning canvas.
6. **Concept 05: Foundational Data Structure Matrix**
   - Searchable and filterable cheat sheet matrix detailing Access, Search, Insert, Delete, and Space complexities for major data structures.
7. **Concept 06: Silicon Bitwise Logic & ALU Arithmetic**
   - Interactive 8-bit registers ($A$ and $B$) with single-cycle bit toggling, boolean gates ($AND$, $OR$, $XOR$, $NOT$), bit shifts ($<<$, $>>$), decimal/hexadecimal readouts, and truth tables.
8. **Concept 07: Knowledge Evaluation Quiz**
   - Interactive multiple-choice challenge with immediate architectural rationale feedback and score tracking.
