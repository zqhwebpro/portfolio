01 // WHAT IT IS

What It Is & Educational Purpose

The 8 Fundamental Concepts of Algorithms is an interactive computer science curriculum designed to make theoretical concepts tangible. Rather than reading abstract pseudocode in textbooks, developers and students interact with living state machines—manipulating arrays, traversing tree nodes, stepping through recursive calls, and observing how operations scale mathematically under load.

The interface features a crisp, high-focus architectural aesthetic with live step controls, complexity comparisons, and memory stack inspectability.

02 // ARCHITECTURE & STATE STEPPING

Engineering & Interactive Visualization

Engineered with modular React state management and responsive vector visualization:

  • Deterministic Step-by-Step Execution

    Each algorithm decomposes into an immutable sequence of micro-states, allowing users to step forward, scrub backwards, or play continuous simulations with visual node highlighting.

  • Live Big-O Asymptotic Graphs

    Dynamic SVG coordinate curves compare O(1), O(log n), O(n), O(n log n), O(n²), and O(2ⁿ) time complexities against current input size N in real time.

  • Call Stack & Activation Frames

    Recursive procedures (such as Fibonacci and QuickSort) visually push and pop activation frames on a virtual call stack, demystifying base-case returns and memory overhead.
