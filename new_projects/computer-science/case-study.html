01 // WHAT IT IS & PURPOSE

Demystifying Core Algorithms

Computer science curricula often teach algorithms through dry mathematical proofs or static blackboard diagrams. Without an intuitive mental model of how data structures shift in memory and how pointers traverse arrays, learners struggle to comprehend why O(n log n) sorting outperforms O(n²) or how recursive call stacks consume memory.

The 8 Fundamental Concepts of Algorithms is an interactive educational workbench built to solve this. It provides granular, micro-step visualization of computer science algorithms—allowing users to step forwards and backwards through execution states, watch code lines light up synchronously, and hear tactile audio cues as pointers inspect, swap, and partition elements.

03 // CODING TECHNIQUES & IMPLEMENTATION

Engineering Mechanics & Algorithms

1. Discrete Time-Travel State Stepper Architecture

In a standard algorithm animation, developers often rely on setTimeout or async/await sleeps. However, this makes it nearly impossible to pause, reverse, or scrub to an arbitrary point in execution without race conditions.

In this application, algorithms are executed ahead of time by an immutable State Frame Generator. The generator records every intermediate state into a snapshot list, enabling seamless forward and backward scrubbing: 

// Precomputes all execution micro-steps for Binary Search
function generateBinarySearchFrames(arr, target) {
    const frames = [];
    let left = 0;
    let right = arr.length - 1;

    frames.push({ left, right, mid: null, status: 'INITIAL', lineKey: 'init' });

    while (left <= right) {
        const mid = Math.floor((left + right) / 2);
        frames.push({ left, right, mid, status: 'COMPUTING_MID', lineKey: 'mid' });

        if (arr[mid] === target) {
            frames.push({ left, right, mid, status: 'FOUND', lineKey: 'found' });
            return frames;
        } else if (arr[mid] < target) {
            left = mid + 1;
            frames.push({ left, right, mid, status: 'SHIFT_RIGHT', lineKey: 'shift_right' });
        } else {
            right = mid - 1;
            frames.push({ left, right, mid, status: 'SHIFT_LEFT', lineKey: 'shift_left' });
        }
    }
    frames.push({ left, right, mid: null, status: 'NOT_FOUND', lineKey: 'not_found' });
    return frames;
}

2. Synchronized Code Line Highlighting

Each snapshot in the frame array contains a lineKey. The code display component inspects this key and dynamically applies an active highlight class to the exact line of code currently executing in the mental model: 

function CodePanel({ concept, activeLineKey }) {
    return (
        <div className="code-body">
            {concept.codeLines.map((line, idx) => {
                const isActive = line.key === activeLineKey;
                return (
                    <div key={idx} className={`code-line ${isActive ? 'active' : ''}`}>
                        <span className="code-linenum">{line.n}</span>
                        <span className="code-text">{line.text}</span>
                    </div>
                );
            })}
        </div>
    );
}

3. Procedural Audio Engine for Multi-Sensory Feedback

The sound engine (soundEngine.js) synthesizes audio cues entirely on the fly using Web Audio oscillators. When a user steps through an algorithm, an exponential ramp gain envelope produces a crisp, tactile click: 

// Synthesizes a tactile mechanical switch click
playClick() {
    if (isMuted) return;
    const ctx = getAudioContext();
    if (!ctx) return;

    const osc = ctx.createOscillator();
    const gain = ctx.createGain();

    osc.type = 'triangle';
    osc.frequency.setValueAtTime(140, ctx.currentTime);
    osc.frequency.exponentialRampToValueAtTime(40, ctx.currentTime + 0.04);

    gain.gain.setValueAtTime(0.12, ctx.currentTime);
    gain.gain.exponentialRampToValueAtTime(0.001, ctx.currentTime + 0.04);

    osc.connect(gain);
    gain.connect(ctx.destination);
    osc.start();
    osc.stop(ctx.currentTime + 0.05);
}

4. Dynamic SVG Asymptotic Complexity Graphing

To provide a tangible sense of Big-O growth rates, the reference table maps mathematical functions directly to SVG coordinate paths. As the user alters the input parameter n from 1 to 100, the visualization dynamically contrasts linear O(n) against quadratic O(n²) and exponential O(2ⁿ): 

// Maps input domain [0, N] to SVG Cartesian coordinates
const computeSvgPath = (complexityFn, maxN, width, height) => {
    const points = [];
    for (let n = 1; n <= maxN; n += (maxN / 50)) {
        const operations = complexityFn(n);
        const x = (n / maxN) * width;
        const y = height - (Math.min(operations, 1000) / 1000) * height;
        points.push(`${x.toFixed(1)},${y.toFixed(1)}`);
    }
    return `M ${points.join(' L ')}`;
};
04 // ARCHITECTURAL TAKEAWAYS

Production Takeaways & Engineering Decisions

  • Precomputed Frames Over Async Timers

    Generating an array of immutable state frames before rendering allowed seamless time-travel scrubbing (both forwards and backwards) without any concurrency bugs or memory leaks.

  • Dual-Plane Code Synchronization

    Simultaneously highlighting code lines alongside active data structure elements connected abstract syntax to physical memory layout in the learner's mind.

  • Procedural Audio as Cognitive Reinforcement

    Pitch-shifting audio feedback as algorithms traversed deeper into recursive trees provided immediate acoustic intuition for call stack depth.
