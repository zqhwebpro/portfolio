The 8 Fundamental Concepts of Algorithms

An interactive Neo-Brutalist educational platform teaching the core foundations of computer science: Algorithms, Data Structures, Complexity, Big-O, Recursion, Divide & Conquer, and Brute Force.

Project Overview

Computer science education often suffers from excessive abstraction and static mathematical formulas. This project translates core theoretical algorithms into tactile, interactive visualizations that allow students and engineers to step through sorting races, recursive call stack frames, and Big-O efficiency curves in real time.

Technical Highlights

Interactive Algorithmic State Machines: Built visual step-through visualizers for sorting algorithms (Bubble Sort, Merge Sort, Quick Sort), recursive stack towers, and binary search trees with controllable execution speed and step inspection.

Mathematical Complexity Graphs: Interactive Big-O curve comparisons dynamically illustrate how time/space resource usage scales across O(1), O(log n), O(n), O(n log n), and O(n²).

Neo-Brutalist Bauhaus Design: High-contrast black borders, vivid primary accents, tactile box shadows, and synthesized audio cues create an energetic, highly memorable developer experience.

What I Learned (Core Takeaways)

  • 💡

    Intuitive Learning Through Visual State Transitions

    Abstract recursion and divide-and-conquer logic become instantly comprehensible when represented as stacked DOM frames that visually push, compute, and pop return values.

  • ⚡

    Asynchronous Animation Scheduling

    Visualizing algorithm iterations requires decoupled pacing. Using async generator functions and promise-driven sleep ticks allows smooth pausing, stepping, and speed modulation without blocking the UI.

  • 🎨

    Neo-Brutalist Design Discipline

    Neo-brutalism relies on strict layout grids, sharp contrast ratios, and deliberate color coding. Every accent color serves an educational function (yellow for active pointers, blue for sorted subarrays, red for pivot elements).
