Restaurant Delivery & POS API Setup Guide

Step-by-Step Architecture Onboarding for Restaurant Websites
Onboarding Guide

Welcome to the restaurant delivery configuration hub. To accept orders and dispatch couriers, your restaurant website connects to either a Direct Point-of-Sale (POS) network or an On-Demand Courier Fleet. Follow this guide to configure your credentials, verify the live handshake, unlock your menu catalog, and generate an integrated blank WordPress site.

Step 1
Choose API Model

Select Direct POS (Toast, Square, Clover) for direct kitchen tickets, or Courier Fleets (DoorDash, Uber Direct) for on-demand drivers.

Step 2
Get Developer Keys

Use each provider's Setup Link to open their developer portal and generate your Client ID, Secret Key, and Store Location GUID.

Step 3
Verify Handshake

Click Configure API on your chosen platform below, paste keys (or click 1-Click Demo), and run the TLS 1.3 encrypted authentication test.

Step 4
Deploy Blank WP Site

When verified, the Menu Items catalog unlocks, and the bottom bar enables: "create site with this configuration" for instant WordPress delivery setup.

No APIs are currently preconnected (0/6). Please choose a delivery provider below and click Configure API to get started.
