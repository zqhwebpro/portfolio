Parma Sub & Fry Co: ASP.NET Core 9 & Toast POS Delivery

An authentic Central Pennsylvania pizzeria & grill platform modeled directly after Parma Pizza & Grill, engineered with a decoupled .NET 9 C# Clean Architecture, community events calendar API, and direct Toast POS delivery integration.

.NET 9 C# Solution ASP.NET Core Web API Community Event Engine Toast POS API v2 Clean Architecture
KEY TAKEAWAYS // ENGINEERING SUMMARY

Engineering the Parma Sub & Fry Co platform demonstrated how Clean Architecture and decoupled ASP.NET Core 9 Web APIs can seamlessly bridge enterprise restaurant POS systems with custom customer-facing digital storefronts. Implementing direct Toast POS API v2 webhook listeners and order ingestion pipelines eliminated third-party commission overhead while routing orders to live Kitchen Display Systems with zero perceptible latency. Modeling relational entities with Entity Framework Core and SQLite in-memory development databases provided deterministic testing grounds for menu modifiers, tax calculation matrices, and localized delivery geofencing. The project confirmed that modern C# and ASP.NET Core provide enterprise-grade reliability, type safety, and scalability for mission-critical e-commerce operations.
