ASP.NET MVC 5 Architecture Map

Enterprise N-Tier Solution Architecture Breakdown

1. TimberlineStore.Domain (Core Logic)
  • Entities/Product.cs: Core domain model with DataAnnotations.
  • Entities/Cart.cs: Encapsulates cart lines, quantity modifications, and total computation.
  • Abstract/IProductRepository.cs: Repository pattern abstraction for zero DB coupling.
  • Concrete/EFProductRepository.cs: EF6 implementation querying SQL Server via DbContext.
2. TimberlineStore.WebUI (Presentation Layer)
  • Controllers/ProductController.cs: Paginated product list view with category and LINQ search filtering.
  • Controllers/CartController.cs: Session-decoupled cart management and checkout orchestration.
  • Infrastructure/Binders/CartModelBinder.cs: Custom ASP.NET model binder managing cart session state.
  • HtmlHelpers/PagingHelpers.cs: Custom Razor extension generating pagination links.
  • App_Start/NinjectWebCommon.cs: Dependency Injection IoC container setup.
