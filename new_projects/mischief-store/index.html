ASP.NET MVC 5 Architecture Solution

1. MischiefStore.Domain (Core Class Library)
  • Abstract/IProductRepository.cs: Decoupled repository contract exposing IQueryable<Product> Products.
  • Concrete/EFProductRepository.cs: Entity Framework 6 implementation connected to EFDbContext.
  • Entities/Product.cs: POCO domain model with DataAnnotation validation rules.
  • Entities/Cart.cs: Pure domain cart encapsulating line-item calculations.
2. MischiefStore.WebUI (Presentation Layer)
  • Controllers/ProductController.cs: Paginated product list view with category and LINQ search filtering.
  • Controllers/CartController.cs: Session-decoupled cart management and checkout orchestration.
  • Infrastructure/Binders/CartModelBinder.cs: Custom ASP.NET model binder managing cart session state.
  • HtmlHelpers/PagingHelpers.cs: Custom Razor extension generating pagination links.
  • App_Start/NinjectWebCommon.cs: Dependency Injection IoC container setup.
