ASP.NET MVC 5 Architecture Map

1. MischiefStore.Domain (Core Class Library)
  • Abstract/IProductRepository.cs: Repository interface exposing IQueryable<Product> Products.
  • Concrete/EFProductRepository.cs: Entity Framework 6 implementation querying database via EFDbContext.
  • Entities/Product.cs: POCO domain entity with DataAnnotations and BLOB imageData.
  • Entities/Cart.cs: Pure domain cart containing collection of CartLine items.
2. MischiefStore.WebUI (Presentation Layer)
  • Controllers/ProductController.cs: Paginated product catalog view with category and search filters.
  • Controllers/CartController.cs: Session-decoupled cart management and checkout dispatch.
  • Infrastructure/Binders/CartModelBinder.cs: Custom ASP.NET model binder pulling Cart from Session.
  • HtmlHelpers/PagingHelpers.cs: Custom Razor extension generating pagination links.
  • App_Start/NinjectWebCommon.cs: Dependency Injection container lifecycle and bindings.
