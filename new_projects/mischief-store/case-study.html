Mischief Store: Enterprise ASP.NET MVC 5 Blueprint

A functional architectural blueprint and e-commerce application demonstrating decoupled N-tier architecture, dependency injection, custom session model binding, and back-office CRUD management.

Project Overview

Mischief Store bridges backend software architecture and frontend UI/UX design. It showcases an enterprise-grade ASP.NET MVC 5 e-commerce application accompanied by an interactive blueprint system that maps every on-screen UI element to its corresponding C# controller, Razor view, domain entity, and repository contract.

Technical Highlights

Decoupled Repository Pattern: Abstracted data access behind IProductRepository contracts resolved at runtime via Ninject Inversion of Control (IoC), enabling effortless swapping between EF6 SQL databases and in-memory mock stores.

Custom Cart Model Binding: Implemented a custom CartModelBinder that decouples controllers from the raw HttpContext.Session, injecting clean Cart domain objects directly into action methods.

Full-Featured CRUD Administration: Back-office product manager allowing inventory creation, editing, category tagging, and validation rules with immediate persistence.

What I Learned (Core Takeaways)

  • 🔌

    Dependency Inversion & Testability

    Injecting dependencies through constructor interfaces rather than instantiating concrete DbContext instances within controllers makes the entire codebase testable, modular, and resilient to database provider changes.

  • 🛒

    Custom Model Binders for Clean Action Signatures

    Leveraging ASP.NET Model Binders to encapsulate session retrieval logic prevents repetitive session boilerplate in controllers and keeps action methods focused purely on application orchestration.

  • 🔍

    Interactive Blueprint Code Tooltips

    Providing hover tooltips that expose exact file paths (e.g., Controllers/ProductController.cs) and architectural responsibilities transforms an e-commerce UI into a powerful educational portfolio piece.
